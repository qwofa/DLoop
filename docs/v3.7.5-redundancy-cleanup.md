- 将重复的计划覆盖要求合并到计划拆分章节，保留延期、复用及依赖缺失结果的承接要求。

- 测试运行器增加文件、名称与业务/集成分层筛选，记录每项用例含自身准备和清理的耗时及最慢十项，另列包含共享准备的整组耗时。空集合、失败和未登记跳过仍使运行失败，CI 默认不缩减覆盖。
- 业务测试按类显式隔离无关历史快照写入；真实 Git/SVN、UI、命令行、快照与 Windows 权限测试继续使用真实边界。默认帮助器保留真实快照，不引入生产开关。用法见 [CI 与测试](ci.md)。

- 核心清理：删除已撤销的需求/实施 UI 前置计算、不可达阻断、恒空配置投影和旧需求评估分支；删除无消费返回链、参数、常量、局部值，以及工作区/档案验证的重复判断。契约正文取消恒真包裹，所有实际契约检查保留。

- 合并重复截图复用说明，去掉旧轻重配置和开发差分措辞；删除旧路径/历史标题/分页参数断言、3 段原项目私有安装态要求、无调用测试帮助器及无用导入/读取/赋值。

当前公开命令、作业格式、审批和工作区占用规则保持原有语义，不引入新状态、兼容分支或迁移机制。删除两个只验证旧同步入口的测试；未知配置检查改用仍存在的初始化入口。
