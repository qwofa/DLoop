# 3.7.2：交互补全与统一交付展示

本版让 DloopUI 在实施完成后展示与实际实现一致的交互说明。初期不完整的标注作为内部设计资料，不能代替完整需求，也不再要求用户例行批准。普通 DLoop 的需求确认和自动冻结规则不受影响。

## 实施与核对

实施任务完整读取需求与设计，逐个功能单元检查相关后端、已有代码和实际界面。发现原范围内有明确依据的遗漏时，补齐实现、设计、交互数据及验证；后端字段存在本身不能证明应新增交互。缺少业务事实、出现冲突或超出授权范围时，只提出具体问题。

候选评审从原始需求检查实现，并从实际实现反查交互说明。最终接受候选后再做整体双向核对，提交每个操作的条件、动作、反馈、结果、实现验证状态与实际证据。工具检查结构、引用、文件变化和当前候选绑定；业务语义与行为验证仍由实施、独立评审和实际验证承担，不能由表格齐全推断为无遗漏。

隐藏、动态生成、没有截图或无法可靠定位的交互仍在文字中展示。一个需求中的隐藏目标不会抹掉其他可见操作。必要实现或验证未完成时不能标记最终材料就绪；明确延期内容保留原因和依据。

## 固定模板

所有输出经 `ui-publish` 使用 `plugin/dloop/runtime/templates/ui-delivery.html`，模板随安装与卸载统一管理。业务数据只维护在当前交互输入及受管模型中，不手改生成页面，不为每个任务另写 HTML。

- 主要材料：`06-validation/ui-delivery.html`，内嵌图片和数据，可离线打开。
- 界面顶部显示业务名称和真实 UI 文件名；功能点显示对应元素名及用途，完整预制体路径和节点层级路径可复制。关联元素合并在原功能点内，无实际节点关联时不猜测名称。
- UI 在左、常驻详情抽屉在右，每次只展示选中的一个功能点；支持点击编号、下拉选择和前后切换，图片与详情各自滚动；直接展示业务内容，去除通用页头与流程描述。一个功能点一个编号，多操作合并在该功能说明内，核对依据默认展开，可手动收起。编号位于截图外侧，以引线指向真实目标；支持页面切换、缩放、拖动与编号/说明双向选择。
- 所有交互保留在列表中，隐藏位置与未验证状态明确显示；规划截图只证明采集时的位置。
- 归档材料：`04-plan/ui-annotation-plan.md` 与保留原图尺寸、外加编号边栏的 SVG，使用同一份数据生成交互表格和依据。

## 最终验收

材料交接沿用既有任务包、候选提交与 UI 模型。任务包按验收场景声明交互、元素定位、截图和验证依据及必要性；实施者通过候选入口交回实际文件，程序检查缺项、文件、截图与节点关联，独立评审直接取得这些材料。实施中可追加同范围要求，不能削减原要求或借材料更新扩展业务范围。

最终输入通过 `prepare-action-input --input-kind ui-delivery` 准备，返回已交材料清单。协调者只补整体双向核对和证据，`ui-publish` 自动汇总已接受任务的交互。材料返修通过 `material_updates` 替换受影响引用，保留其他材料和已修订引用；只在对应 UI 变化时更新截图与定位。缺材料明确报出场景和材料类型，必要验证未通过时阻止正式交付。程序保证材料交接与模板生成的确定性，语义遗漏仍由双向核对发现。

调研简报可用 `refresh_prefabs` 指定需要补拍的页面；其余经过身份、内容或定位核对后复用。空列表不调用 Unity，未核对的资产变化会得到具体补拍或补核对提示。重新调研保留已修订的任务材料引用；关联 UI 变化仍须更新对应材料。

仅修改文案或业务逻辑且截图定位未受影响时，先核对节点、布局、画布及相关依赖，再在调研简报中同时提交 `refresh_prefabs` 和 `unchanged_layout: [{"prefab": "Assets/UI/ExamplePanel.prefab", "reason": "具体改动及定位未变的核对依据"}]`。这是一份 AI 实施核对记录，不是用户批准门；不能用它掩盖位置变化。工具保留原图、节点区域及原始采集资产摘要，绑定本次已核对资产；HTML 和归档明确展示历史位置参考及原因。再次修改资产必须重新核对，身份变化、图片缺失或图片变化仍需补拍。正式材料中的交互与验证结论仍须跟随实际行为更新。

正式发布自动绑定当前已接受实现候选及归档中的完整需求、设计。状态视图提供 HTML、归档表格与当前摘要。展示之后等待真实用户回复，再记录最终阶段决定；材料或实现变化后重新核对、生成并验收受影响结果，旧回复不能覆盖新内容。最终验收有效后才允许封存。

## 范围与交付边界

版本状态为 `frozen`，基于 v3.7.1，由 `v3.7.2` 标签固定。不迁移旧档案，不扫描全项目所有交互，不改造 Unity 截图器，也不提供在线编辑器或额外托管服务。

验证覆盖公开流程、交互补全、当前材料和候选绑定、封存门禁、固定模板打包、安装卸载及既有快照流程；真实浏览器另检查桌面与窄窗口下的文字、截图和交互。浏览器模板检查不能替代使用项目中的 Unity 运行验证。
