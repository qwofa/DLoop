## 交付范围

- 生成器预检：任务包增加可选的 `generated_write_scope`，接收项目已有只读预检查的预计写入清单。契约登记和开工均核对授权覆盖；没有生成操作时留空。预制体绑定信息、生成脚本和新增元文件一并考虑，工具不扩大授权、不改造项目生成器。
- 产物归属：编辑器采集请求与临时截图使用当前版本的 `captures/<feature-id>/`；内部 UI 模型属于工作流材料，不作为产品写入范围。真实产品改动仍接受范围检查，正式证据继续接受来源、新鲜度及候选绑定检查。
- 重试预检：原范围外变化尚在时，拒绝再次启动，返回具体路径、生效版本与现有恢复入口。保留状态、成果和执行身份历史，处理后可使用同一未消耗身份重试。
- 具体指引：内部需求材料未就绪时提示文档和原因，不引导人工需求批准；UI 校验保留真实缺项；重复启动提示生效身份和契约；材料引用明确一条一个文件。
- 草稿复用：正式材料输入尚不可用时指向现有 `ui-publish` 内部草稿路径，继续使用原截图、交互与统一模板。草稿不产生批准、候选或冻结。
