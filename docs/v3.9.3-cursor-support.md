# v3.9.3 Cursor 宿主支持

状态：`frozen`。冻结日期：2026-09-23。基于公开主线 v3.9.2。目标是让 Windows 本地 Cursor Agent 用户使用现有 DLoop 与 DloopUI 工作流，并保留 Codex 入口。

## 范围

- 两个 Skill 继续安装在项目的 `.agents/skills/`，在 Cursor 用 `/dloop`、`/dloop-ui` 显式调用，在 Codex 用 `$dloop`、`$dloop-ui`。
- 正式档案、快照、分享材料和安装锁继续使用项目内统一路径；不按宿主分叉。跨版本升级仍将旧作业归档失效。
- 增加 Cursor 的 Unity MCP 连接与本地 Agent 使用说明；安装器不改写用户的 Cursor 配置。
- 独立评审继续使用当前宿主的原生子 Agent。当前范围不包含 Cursor Cloud Agent 与远程 Unity Editor 的端到端验证。

## 验证范围

- 检查版本、Skill、安装载荷和统一档案路径的一致性。
- 在隔离 Git/SVN 项目测试安装、校验与卸载，以及新版档案路径。
- 在 Cursor 本地 Agent 中检查 Skill 发现、显式调用、Unity MCP 与原生子 Agent；真实 Unity 采集需可用编辑器环境。

公开主线合并并发布 `v3.9.3` 标签后，一行入口安装本版；源码安装使用当前冻结源码。

调整为 3.9.3 后，发行一致性 9 项、档案路径 16 项、快照 26 项，以及源码安装、在线入口和版本交替检查均已通过。Cursor 图形界面未能在当前计算机控制接口中枚举到窗口，因此 Skill 列表、Unity MCP 和真实编辑器操作尚未做端到端验收。SVN 中文工作副本路径测试在未修改的 v3.9.2 基线也会因当前环境的路径编码失败。
