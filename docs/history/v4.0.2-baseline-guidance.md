# v4.0.2 开工指引与切片依赖范围

状态：`frozen`。冻结日期：2026-10-21。基于已发布的 v4.0.1，按修订版本递增。

## 范围

- 开工清单包含缺项时，提交结果复用状态查询的下一步判断，CLI 与 MCP 使用同一规则。
- 内部需求文档尚未齐备时先补文档；进入材料核对阶段后，由协调者先调查缺项，仅将无法查明的业务事实或决定交给用户。
- 计划正文必须简短说明可分别验收的结果；合并（含单一大切片）需解释不可分依赖或交接收益，不能仅凭共享文件、同一连接或不要求联调决定。
- 同一开工清单通过 `slice_requirements` 映射批准方案中的切片及其直接使用的需求；完整覆盖范围，共同材料显式列入所有消费者，前置及替代关系传播影响。
- 局部缺项只阻断直接消费者及后续依赖者。用户可在原开工确认入口确认材料齐备的独立切片；缺项仍保留，不自动延期、取消或记为完成。
- 原批准记录保存已确认切片的依据摘要；材料及依赖未变化的切片沿用确认，受影响切片补齐后重新确认。状态、启动、提交、返修和交接一致检查。
- 没有明确映射或整体范围不完整时先调查；单线修改租约、独立候选评审和完整最终验收仍保留，不新增审批阶段或第二套任务状态。

## 验证范围

- 回归覆盖调查未找到预制体、内部需求文档尚未齐备时，经 CLI 和 MCP 提交缺项清单，下一步与状态查询一致，正式批准状态不变。
- 复核材料核对阶段的四类缺项仍阻断实施和批准，并继续提示协调者调查。
- 2026-09-28 定向回归共 31 项通过：开工清单及批准行为 16 项、发行元数据 9 项、Git/SVN 安装生命周期 5 项、真实快照保存恢复 1 项。结构化批准用例首次因默认 Python 缺少测试依赖未运行，使用项目声明的 MCP 依赖环境复验通过。
- 安装验证覆盖普通、嵌套及关联 Git 工作区的安装、校验、重装、卸载，以及 SVN 首次安装和完整卸载；快照回归核对原始字节、删除与暂存区保留。
- 2026-10-21 新增四组按切片回归，覆盖独立切片实施及候选评审、直接与传递依赖、共享材料、完整映射、局部批准保留、依据补齐后的重新确认、运行中中断与切换、计划依赖变化及纯措辞修订。
- 本轮扩展回归共 298 项：修正并复验后 297 项通过，1 项受本机 SVN 中文路径问题阻断。覆盖 UI 交付、上下文、执行、批准、方案、契约、交接、输入、模板及发行安装；真实 Unity 操作与模型是否正确理解业务依赖仍需实际使用验证。
- 本机 SVN 中文路径测试在准备阶段将中文目录名创建为乱码，尚未执行安装器即失败；普通路径及带空格、符号的路径继续通过。该环境问题单独保留，不改动安装逻辑来绕过。
