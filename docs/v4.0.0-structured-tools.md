# v4.0.0 结构化工具入口

状态：`frozen`。冻结日期：2026-09-24。基于本地 v3.9.4；公开基线为 v3.9.3。本版尚未公开发布。

## 范围

- 六个 MCP 工具覆盖状态、当前输入模板，以及任务包、检查点、候选和 UI 开工清单提交。
- 调用者直接提供对象，工具在规范阶段目录保存无 BOM UTF-8 输入；同一内容复用同一输入材料。
- CLI 与 MCP 共用业务执行入口；沿用工作区锁、范围检查、批准、独立评审、快照及业务失败摩擦记录。
- 官方 MCP SDK 负责通信与协议协商；服务绑定安装项目，升级后要求重启。依赖和宿主配置见[连接说明](structured-tools.md)。
- 保留其余 CLI 动作，不增加流程阶段、自动批准、恢复数据库或第二套业务状态。

## 验证范围

- 真实 MCP 子进程的工具发现、参数结构、项目绑定、两种协议客户端及升级后重启提示。
- 真实 Git 项目通过结构化任务包、CLI 开工、并发重复检查点、候选提交与独立评审；检查快照、单一检查点及重复候选拒绝。
- 输入准备不写模板文件；业务失败保留原门禁和摩擦；UI 缺材料仍阻断，齐备后仍需用户确认，纯措辞调整保留已有批准。
- 完整核心回归 448 项、安装发行回归 56 项均无失败；核心源码安装归属检查与真实 Unity 采集各按既有环境规则跳过一项。CI 结果处理另有 10 项通过，实际 uv 启动及工具发现通过。结果在本地验证记录中保存。
- 真实 Unity 编辑器操作及 Codex/Cursor 界面的模型决策不属于本次自动化验证。

## 使用边界

结构化调用消除手写 JSON 文件、路径和编码的操作摩擦。复杂业务内容仍按工具返回的当前模板填写并由原业务校验确认；无法替代材料准备、真实验证或用户决定。当前仅覆盖六个高频工具，剩余动作继续使用 CLI。

版本进位按仓库三段单数字规则从 3.9.x 到 4.0.0。旧作业仍在升级时归档失效，原材料与代码改动保留。
