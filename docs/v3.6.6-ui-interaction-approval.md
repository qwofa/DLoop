# DLoop 3.6.6：实施前的 UI 交互人工确认

基于冻结版 `v3.6.5`（v3.6.5），按用户指定版本开发 3.6.6。用户于 2026-09-10 授权冻结、创建 PR 并合入，当前为 `frozen`，由 `v3.6.6` 标签固定；本次冻结不包含安装到目标项目。目标是修正 DloopUI 中详细需求和机器规划通过后直接实施、用户没有机会审核具体交互的缺口。下文保留开发阶段验证记录。

## 用户可观察行为

- 显式 DloopUI 有新增或修改交互时，首次实施前展示完整需求场景和真实界面标注，等待用户明确回复；没有新增交互但存在缺失或不可见目标时，也展示承接与延期影响。
- 场景说明入口、操作、结果、跨窗口衔接、关键条件、不处理行为与受影响位置；原需求与 AI 新增选择可区分。正文继续位于需求入口，视觉定位复用标注计划，不创建场景账本、原型系统或逐控件状态矩阵。
- 需求共识已经展示同一完整方案时，一次回复可同时确认需求与交互；仅有详细开发提示不能代替对整理方案的审核。
- 已确认的行为不变时连续推进。交互、目标、结果或缺项处理变化后只展示差异及影响，重新确认完整当前方案；排版、重新截图和纯内部设计调整不重复询问。全部为真实无需产品修改的复用且没有跳过项时不增加交互关口。
- 最终验收仍然检查实际实现与验证边界。

## 实现与授权边界

沿用 `stage-action` 和同一 `approvals` 状态，增加 `ui-interaction` 决定。工作流状态格式更新为 6，仅支持当前版本作业，不迁移或继续旧档案。普通 DLoop 不显示或要求这项决定。

UI 批准复用需求入口快照，另绑定已发布模型中需求、目标 Prefab、标注目标/操作/结果和跳过说明的业务摘要；不绑定截图字节与标注坐标。需求语义版本参与摘要，非语义排版修改仍核对正文确认及依赖新鲜度，但不重新要求人确认。新增交互必须写回需求场景和标注；设计只承载内部实现选择。

展示版本由 `workflow-status` 返回的 UI 确认材料及 `reviewed_digest` 定位，批准必须提交同一摘要与用户回复定位/原文。需求批准可通过 `--include-ui-interaction` 在一次事务中合并记录。程序检查材料、摘要及用户依据非空；不接入宿主对话认证，不能证明填写的回复真实来自用户。Skill 明确禁止 AI 从机器 PASS、旧开发授权或沉默自行登记确认。

未确认、拒绝或失效时，统一交付视图要求人工决定，实施交接不输出可执行合同；启动、返修、检查点、候选提交与评审共用实施输入门禁，最终批准和批准有效性也检查 UI 确认。最终批准另绑定验收时完整 UI 方案的展示摘要，包括纯复用方案；新方案获批不会恢复旧最终验收，必须重新完成最终验收。规则在 UI 常驻入口、协调入口、实施模块及专属审批动作明确投递。

## 验证

验证公开命令路径：规划 PASS 后等待、未批准无法启动和交接、缺用户依据与旧展示版本拒绝、批准后启动、合并确认、方案变化失效、拒绝保持阻断、纯复用不额外确认、目标不可见仍需确认，以及原有普通 DLoop 流程。

同时运行工作流回归、发行一致性、临时项目安装与卸载及两份 Skill 结构校验。使用现有模拟截图夹具验证工作流，不改变 Unity 截图器或游戏代码，不把命令测试称为真实模型行为或用户交互验收。

## 2026-09-10 验证结果

- 工作流全量 344 项：343 通过，1 项源码环境安装态检查按条件跳过。首次回归发现常驻入口超出既有 8 KiB 限制，精简新增说明后通过，未放宽限制。
- UI 公开命令回归 18 项通过，包含本版新增的 6 个场景。覆盖未审批启动与交接阻断、用户依据缺失、展示版本过期、拒绝、合并确认及失败原子性、需求与标注变化失效、实施检查点阻断、最终接受失效、纯复用豁免、不可见目标仍需确认，以及真实命令重新采集后截图字节与标注坐标变化不要求重审。截图为现有测试适配器产生的夹具。
- 材料刷新不完整时先提示重新发布标注，材料就绪后才要求人审核；相关回归通过。预期审批阻断归入保护事件，不计为工具故障。
- 发行、安装卸载与轻量 UI 共 36 项：真实 Unity 采集 1 项因没有独立编辑器测试环境跳过，其余最终均通过。首次安装回归有 1 项因执行期间继续修改了被打包的测试文件，被暂存哈希校验拒绝；停止修改后单独重跑该测试及其子场景通过（约 40 秒），未修改安装器绕过检查。
- 最后相关回归：UI 18 项、上下文 41 项、故障归因 6 项通过；两份 Skill 的结构校验与差异空白检查通过。
- 审查修复：补充正常需求语义更新、标注发布与重批流程，先复现旧最终验收自动恢复，再加入最终验收的 UI 方案绑定。单独确认、合并确认及转为纯复用都不会恢复旧最终验收；重新最终验收可恢复，相同方案重复发布和非语义排版保留批准。修复后 UI 18 项、发行一致性 10 项通过，工作流全量 344 项中 343 通过、1 项源码环境安装态检查按条件跳过。
- 未运行独立模型行为实验，不宣称已经证明 AI 在真实对话中的审批遵从率。程序不认证用户回复来源，Skill 要求如实引用对应回复。未冻结、创建标签、发布或安装到目标项目。
