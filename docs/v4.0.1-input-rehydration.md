# v4.0.1 输入回填修复

状态：`frozen`。冻结日期：2026-09-24。基于已冻结的 v4.0.0；公开基线为 v3.9.3。本次修复既有输入准备行为，按修订版本递增，不复用冻结编号。

## 范围

- 再次准备 UI 开工清单时，带回同一业务依据下的已登记材料、用途和仍属于当前来源的范围排除。
- 需求或来源依据变化时，按当前调查生成预制体与需求来源，保留旧协议、配置线索并标为待核实；新增需求保留待填项，不沿用其他需求的材料。
- 再次准备同一任务包时，从正式登记内容投影允许提交的输入字段，保留范围、上下文、契约和交付要求；新任务包仍使用新建模板。
- 缺项先由协调者调查，提交返回与状态查询保持一致；业务事实或决定确实缺失时再集中询问用户。
- CLI 与 MCP 共用上述准备规则。准备不修改正式记录或批准，CLI 不覆盖未提交编辑；既有输入文件应按返回模板对照更新。

- 14 项定向验证通过：CLI 与 MCP 回填一致、准备不修改正式状态或未提交编辑、范围排除保留、单项措辞修订保留有效批准、依据变化需复核、新任务和新需求仍待填写，以及任务包重交与非法同版本修改。
- 完整核心回归 452 项：451 通过，源码安装归属检查按既有环境规则跳过 1 项。确认页“待核实或选择”文案调整后，两个相关用例另行复验通过。
- 安装发行回归 56 项：首次 53 项通过、真实 Unity 采集跳过 1 项；两个用例的三个子场景在准备中文路径 SVN 工作副本时发生环境错误。使用与 CI 同类的 Unicode SVN 客户端后，这两个用例复验全部通过，安装业务代码未因此改动。

## 发布与边界

本版包含尚未公开发布的 v3.9.4 操作摩擦修复与 v4.0.0 MCP 入口；以一个 PR 合入公开主线。没有新增材料数据库、审批阶段或持久状态。

回填保留已登记事实，不替代业务核对或真实验证；依据变化仍需复核并按原规则确认，准备任务包不授予契约修改权限。升级仍整体归档旧作业，不跨版本接续；本次源码发布不自动升级使用项目。
